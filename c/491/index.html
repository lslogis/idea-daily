Pocket Garden — 웹 게임 150개를 담은 가상 콘솔

웹 게임 150개 이상을 한데 모은 가상 게임 콘솔 — 옛날 게임기를 켜듯 브라우저에서 바로 골라서 한다

HN Show HN 신작 — '게임 150개를 모았다'가 아니라 '콘솔'이라는 껍데기가 핵심이다. 낱개로 흩어진 것을 하나의 기계처럼 묶으면 다시 찾게 된다
