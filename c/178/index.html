agentmash — 코딩 에이전트끼리 부딪히지 않게 하는 공유 레이어

팀의 코딩 에이전트들이 서로의 작업 파일을 공유하는 오픈소스 멀티플레이어 레이어. 누가 어떤 이름을 바꾸는지 미리 알려 충돌을 막는다.

Product Hunt 오늘 6위. JS/TS에서는 바꾼 export 이름과 import 관계를 이름 단위로 매칭해, 다른 에이전트가 건드리기 전에 경고를 보낸다. Claude Code·Codex·Antigravity와 연결된다.

업그레이드 각도: '충돌 알림'에서 '병합 심판'으로 키워라. 두 에이전트의 변경을 받아 자동으로 합치고 테스트까지 돌려주는 '멀티 에이전트 PR 봇'이 팀 도입의 결정타다.
