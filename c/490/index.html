Gerber 3D — PCB 파일을 브라우저에서 보고 제작 가능성을 검사하는 도구

PCB 설계 파일(거버)을 브라우저에서 바로 보고, 버전을 비교하고, 공장에 맡기기 전 제작 가능 여부를 검사해주는 도구

HN Show HN 신작 — 무거운 전용 프로그램 없이 브라우저에서 기판 파일을 열어본다는 점이 하드웨어 메이커들의 '그거 필요했어'를 건드렸다

업그레이드 각도: PCB 말고 다른 '만드는 파일' 검수기로 바꿔라 — 3D 프린터용 STL, 레이저커팅용 도면을 브라우저에서 열어보고 오류를 짚어주는 메이커용 검수기가 같은 자리에 있다
