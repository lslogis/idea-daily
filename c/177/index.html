Embage — 고객 응대를 맡기는 에이전트 제작기

고객 응대용 AI 에이전트를 만들고, 하위 에이전트와 맞춤 데이터 테이블을 엮어 반품·문의 같은 다단계 업무를 자동 처리하는 도구.

Product Hunt 오늘 4위. 무료 플랜에서도 내 API 키를 꽂으면 AI 크레딧 마크업 없이 에이전트를 돌릴 수 있고, 런칭 코드로 무료 크레딧을 준다.

업그레이드 각도: '만능 에이전트'에서 '쇼핑몰 CS 전용'으로 좁혀라. 반품·배송·교환 규칙이 미리 박힌 템플릿을 자영업자 몰에 파는 게 '직접 만든다'는 장벽을 낮춘다.
