Penta — 주머니 속 90년대 5단 CD 체인저

아이폰·아이패드·아이폰 Duo를 90년대 5단 CD 체인저로 바꾸는 앱 — 실제 체인저에서 녹음한 클릭·윙 소리까지 재현했다.

PH 오늘의 런칭 — Duo에서는 폰을 닫으면 앨범 케이스가 되고 열면 케이스가 열린다. 무료, Pro는 실제 인쇄 CD 아트.

업그레이드 각도: '추억 가전'을 시리즈로. 카세트 워크맨·미니컴포 같은 옛 기기들을 실제 소리·조작감으로 되살리는 레트로 가전 박물관 앱. 원본이 CD 체인저 하나라면, 당신은 주머니 속 90년대 전자상가다.
