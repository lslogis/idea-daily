shim-cli — 코딩 에이전트가 뭘 보내는지 들여다보기

Claude Code가 모델에 보내는 데이터(.env 키, 개인정보)를 감시하고 마스킹하는 오픈소스 후크.

Product Hunt 오늘 런칭, Apache-2.0 오픈소스. `uv tool install shim` 한 줄이면 설치.

업그레이드 각도: 한국 개인정보(이메일·전화번호·주민번호 패턴) 탐지 룰을 얹은 'K-DLP for Claude Code'로. 에이전트 코딩 도입하는 기업 영업용으로 각이 선다.

출처: Product Hunt
