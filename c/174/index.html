Screen Studio 4.0 — 녹화하면 알아서 예뻐지는 맥 화면 녹화기

맥 화면 녹화 후 자동 줌·배경·모션 블러까지 입혀주는 녹화 앱의 4.0 버전. 유리 돋보기 줌, 카메라 잘라내기, 대본으로 편집이 새로 들어갔다.

Product Hunt 오늘 1위. 2026-11-01 출시 당일 1위를 차지했고, 기존에도 평점 4.9·리뷰 190개로 데모·튜토리얼용으로 검증된 제품이다.
