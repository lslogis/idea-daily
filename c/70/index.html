Uberblok — ZFS 내부를 걷는 인터랙티브 박물관

ZFS 파일시스템의 내부를 인터랙티브 박물관처럼 탐험하며 배우는 웹 전시.

HN 69점 — '기술 문서가 아니라 박물관'이라는 형식 자체가 화제.

업그레이드 각도: 형식을 '어떤 복잡한 시스템'에든 붙여라. Git 내부·TCP 핸드셰이크·DB 인덱스를 박물관 투어로 만드는 시리즈. 원본이 ZFS 하나라면, 당신은 '인프라 박물관'이라는 장르다.
