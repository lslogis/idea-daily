diff-tour — AI가 짠 코드, 시니어처럼 읽는 법을 가르쳐준다

깃 diff를 가져다 시니어 엔지니어의 시선으로 '왜 바뀌었는지, 뭘 의심해야 하는지'를 단계별 투어로 보여주는 도구.

PH 오늘 상위권 — 읽기 전용·서버 없음·MIT, 'AI가 코드를 짜는 시대에 읽는 법을 가르친다'는 문제의식이 통했다.

업그레이드 각도: 코드 대신 '기획서 변경 투어', '법률 문서 변경 투어'처럼 다른 문서의 diff에 같은 투어 형식을 붙이면 비개발자용 학습 도구가 된다.
