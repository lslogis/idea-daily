Stackdome — 내 쿠버네티스에 까는 오픈소스 Railway

Railway처럼 버튼 하나로 앱을 배포하게 해주는 도구를, 남의 클라우드가 아니라 내 쿠버네티스 클러스터에 직접 깔아 쓰는 오픈소스 버전.

HN Show HN 게재 — 'self-hostable Railway alternative on K8s'. 배포 비용·벤더 종속을 피하려는 1인 개발자 수요를 정확히 겨냥.

업그레이드 각도: '배포' 대신 '개발환경 복제'에 집중하라. 새 팀원이 git clone 한 방으로 로컬+스테이징을 통째로 띄우는 원클릭 온보딩 도구 — 원본에 없는 건 '만들기(온보딩)' 부분이다.
